# MiniMax H3 利用条件の案内

ACS ImageGen Lite本体のライセンスとは別に、MiniMax H3 Community License Agreementが適用されます。本アプリはH3のモデル本体を同梱・再配布せず、利用者の操作後に公式のComfy-Org配布元からRunPodへ取得します。

## Lite版での安全ゲート

- `RUNPOD_DC_ID`を確認し、既定では日本リージョン`AP-JP-1`以外でH3を有効化しません。
- 利用者がH3ライセンス、地域、AI生成表示、他AI学習禁止の3項目を確認するまで、H3のダウンロードと動画生成を拒否します。
- 同意記録はRunPodのデータ領域へライセンス版と時刻を保存します。
- 公開UIに`MiniMax H3`の名称と著作権通知を表示します。

## 必ず原文を確認する事項

- Applicable TerritoryはEU、英国、韓国、米国を除外しています。
- 年間売上2,000万米ドル超の事業体等には別途許可が必要です。
- H3または生成物を、他のAIモデルの学習・改善へ使用できません。
- 公開する生成物はAI生成であることを明確に表示します。
- 違法、有害、無断のなりすまし等は禁止です。

ここに記載した内容は法的助言ではなく、原文の要約です。公開配布前に最新の原文と対象地域を確認してください。
