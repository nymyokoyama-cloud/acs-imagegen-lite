# MiniMax H3 通報・調査・停止方針

## 通報窓口

MiniMax H3を使った権利侵害、不適切な生成、地域・安全ゲートの回避などの疑いは、`info@acs-developer.com`へ件名`MiniMax H3 suspected violation`で連絡してください。

可能な範囲で、発生日時、対象URLまたはファイル名、問題の種類、確認できる事実を記載してください。違法・有害なファイルそのものや、不要な個人情報は添付しないでください。

## ACS Developerが行う対応

1. 善意の通報を受けたら、対象版、公開導線、再現可能性、権利・安全上の影響を確認します。
2. 実際の違反または合理的な危険を確認した場合、制御できる範囲で配布停止、テンプレート非公開化、該当版への警告、修正版の公開等を行います。
3. 同じ利用者による違反が継続し、ACS Developerがその配布アクセスを制御できる場合は、そのアクセスの停止または終了を検討します。
4. 安全フィルターと同意・地域ゲートは、通報やライセンス更新を踏まえて定期的に見直します。

## RunPod運営者・利用者が行う対応

ACS ImageGen Liteは利用者自身のRunPod上で動くため、ACS Developerは個々のPodや生成物を遠隔監視・削除できません。Podを他者へ提供する運営者は、自分の利用者にもMiniMax H3のSection VとExhibit A以上の条件を適用し、次を行ってください。

- 通報を受けた生成の停止、対象入力・出力の確認と削除
- 違反ユーザーの一時停止、再発時の利用終了
- 安全機能を無効化しない運用と更新版への追随
- 権利侵害や法令違反が疑われる場合の専門家・関係機関への相談

この方針は技術的・組織的な運用手順であり、法的助言ではありません。公式ライセンス原文が優先します。
