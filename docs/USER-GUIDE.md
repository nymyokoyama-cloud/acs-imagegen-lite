# ACS ImageGen Lite 利用ガイド

## 最初に

初回画面で10文字以上のパスワードを設定します。これはRunPod上の画面を第三者から守るためのものです。忘れた場合に復元する機能はありません。

パソコンは必須ではありません。スマホのブラウザからRunPod起動、モデル取得、画像生成、Pod削除まで操作できます。モデルの保存先はRunPod側で、スマホやパソコン本体ではありません。

## モデルを準備する

画面上部で次のいずれかを押します。

- `Krea2 Turboを入れる`: 初めての方におすすめ。共有ファイル込み約18.6GB
- `Krea2 Rawを入れる`: 品質優先。Turbo導入済みなら約13.1GB追加
- `Turbo＋Rawをまとめて準備`: 合計約31.8GB

容量、ファイル名、進捗、安全確認の状態が表示されます。途中で中断しても`.part`を保持し、次回は続きから再開します。

## 画像生成

1. モデルを選びます。
   - Turbo: 8 steps、速さ優先。ネガティブプロンプトは使用しません。
   - Raw: 24 steps、品質優先。ネガティブプロンプトを使用できます。
2. プロンプトを入力します。
3. 比率とスタイルを選びます。
4. Seedは再現したい場合だけ整数で指定します。空欄ならランダムです。
5. 「キューへ追加」を押します。
6. 完成画像を開いて端末へ保存します。

## LoRA

「自分のLoRAを追加」を開き、`.safetensors`ファイルをアップロードします。ファイル名は半角英数字、ハイフン、アンダースコア、ドットだけにしてください。

生成フォームでLoRA、強度、必要なトリガーワードを指定します。異なる基盤モデル向けのLoRAは正常に効かないため、Krea2対応を確認してください。配布元の利用条件も必ず確認してください。

## 終了操作

- GPUを停止: Podとデータを残します。ストレージ料金は継続します。
- Podを完全削除: GPU課金を止めます。Network Volume未使用時はモデルも消え、継続ストレージ料金を残しません。

画像を保存してから終了してください。Lite UIは既定でアイドル20分、最大180分の監視を行いますが、RunPodコンソールで実際の停止状態を確認してください。

## Lite版の範囲

Lite版はText to Image専用です。Depth、ControlNet、動画生成、LoRA学習、人物別プリセット、外部ストレージ連携は含みません。
