# ACS ImageGen Lite 利用ガイド

## 最初に

初回画面で10文字以上のパスワードを設定します。パソコンは必須ではなく、RunPodの準備後はスマホのブラウザだけでモデル取得、画像・動画生成、保存、終了操作まで行えます。

Krea2を使う前に公式ライセンスPDFとAcceptable Use Policyを読み、画面の5項目を確認します。商用利用は関連会社を含む会社全体の直近12か月売上が100万米ドル未満の場合に限られ、以上の場合はKreaのEnterprise Licenseが必要です。

Z-Image TurboはApache License 2.0で公開されており、同意ゲートはありません。いちばん軽くGPU代も抑えられるので、最初の1本としておすすめです。

## モデルを準備

- `Z-Image Turbo`: いちばん軽い画像生成、約12.2GB。16GB級GPUで動きます
- `Krea2 Turbo`: 高速画像生成、約18.6GB
- `Krea2 Raw`: 品質優先。Turbo導入後は約13.1GB追加
- `MiniMax H3 動画`: 3種類の動画生成、約53.9GB
- `おすすめ：Krea2 Turbo + MiniMax H3`: 約72.6GB
- `すべて`: Turbo、Raw、Z-Image、H3で約97.9GB

H3は同梱ライセンス全文と日本語の利用条件を読み、地域、AUP、素材の権利、AI表示、他AI学習禁止、通報対応を確認してから取得します。同意記録はこのPodに保存され、条件更新時は再同意が必要です。容量、進捗、SHA-256確認が画面に表示され、中断後は高速転送側のキャッシュを利用して再開します。大きい1ファイルの進捗は完了時にまとまって動く場合があります。

## 画像生成（Krea2 / Z-Image Turbo）

1. `Krea2 Turbo`、`Krea2 Raw`、`Z-Image Turbo`から選びます。
2. プロンプト、比率、スタイルを入力します。比率は3モデルとも5種類から選べます。
3. 必要ならSeedとLoRAを指定します。
4. 「画像生成をキューへ追加」を押します。

Krea2 Turboは8 stepsの速度優先、Krea2 Rawは24 stepsの品質優先です。Rawだけネガティブプロンプトを使えます。

Z-Image Turboは8 steps・cfg 1.0の蒸留モデルで、いちばん軽く速いエンジンです。cfgが1.0のためネガティブプロンプトは使いません。生成設定は公式の蒸留設定に固定していて、変更できません。

LoRAは学習したベースモデルと同じエンジンでだけ効きます。Krea2用LoRAはKrea2で、Z-Image用LoRAはZ-Image Turboで選んでください。合わないLoRAはエラーにならず効果が出ないことがあります。

Lite版は3モデルとも受付時と実行直前に禁止用途を検査します。完成画像は必ず人が確認し、問題がある出力は削除してください。法令や投稿先の規約で必要な場合はAI生成表示を行います。

## MiniMax H3動画生成

- Text to Video: プロンプトだけで動画を作ります。
- Image to Video: 開始画像から動かします。
- First / Last Frame: 開始画像と終了画像の間を動画化します。

モードを選び、プロンプト、比率、3〜10秒、必要なフレーム画像を指定します。PNG、JPEG、WebPを使用でき、1枚25MBまでです。H3は映像と音声を同時生成します。料金確認のため最初は5秒がおすすめです。

フレーム画像はジョブ処理後にLite UIの作業領域から削除します。入力画像や生成物の権利を確認し、無断のなりすましには使用しないでください。代表的なAUP違反はサーバー側安全フィルターが拒否しますが、入力画像と生成結果は利用者自身でも確認してください。

## 公開時の注意

H3生成物を公開する場合はAI生成であることを明確かつ目立つ形で表示します。保存ファイル名にも`minimax-h3-ai`が付きます。H3やその生成物を、H3またはModel Derivatives以外のAIモデルの学習・改善に使用できません。必ず最新のMiniMax H3ライセンス原文を確認してください。不適切な生成や権利侵害は、画面の「ACS Developerへ通報」から連絡できます。

Z-Image TurboはApache-2.0のためAI表示や他AI学習禁止の義務はありませんが、Lite版は識別のため保存ファイル名に`zimage-ai`を付けます。Krea2生成物には`krea2-ai`が付きます。法令や投稿先の規約でAI生成表示が求められる場合は、いずれのエンジンでも表示してください。

## 終了

- GPUを停止: GPU課金を止めます。一時ディスクは消える場合があります。
- Podを完全削除: RunPod APIへ削除要求を送り、結果を表示します。Network Volume未使用時は、完全削除完了後にモデル・履歴も消えます。

生成物を端末へ保存してから終了し、RunPodコンソールで対象Podが消えたことを必ず確認してください。UIがAPI権限エラーを表示した場合は、コンソールから手動削除します。
