# ACS ImageGen Lite 利用ガイド

## 最初に

初回画面で10文字以上のパスワードを設定します。パソコンは必須ではなく、RunPodの準備後はスマホのブラウザだけでモデル取得、画像・動画生成、保存、Pod削除まで操作できます。

## モデルを準備

- `Krea2 Turbo`: 高速画像生成、約18.6GB
- `Krea2 Raw`: 品質優先。Turbo導入後は約13.1GB追加
- `MiniMax H3 動画`: 3種類の動画生成、約53.9GB
- `おすすめ：Krea2 Turbo + MiniMax H3`: 約72.6GB
- `すべて`: Turbo、Raw、H3で約85.7GB

H3は画面の地域・ライセンス・公開時の注意を確認してから取得します。容量、進捗、SHA-256確認が画面に表示され、中断後は途中から再開します。

## Krea2画像生成

1. TurboまたはRawを選びます。
2. プロンプト、比率、スタイルを入力します。
3. 必要ならSeedとKrea2対応LoRAを指定します。
4. 「画像生成をキューへ追加」を押します。

Turboは8 stepsの速度優先、Rawは24 stepsの品質優先です。Rawではネガティブプロンプトを使えます。

## MiniMax H3動画生成

- Text to Video: プロンプトだけで動画を作ります。
- Image to Video: 開始画像から動かします。
- First / Last Frame: 開始画像と終了画像の間を動画化します。

モードを選び、プロンプト、比率、3〜10秒、必要なフレーム画像を指定します。PNG、JPEG、WebPを使用でき、1枚25MBまでです。H3は映像と音声を同時生成します。料金確認のため最初は5秒がおすすめです。

フレーム画像はジョブ処理後にLite UIの作業領域から削除します。入力画像や生成物の権利を確認し、無断のなりすましには使用しないでください。

## 公開時の注意

H3生成物を公開する場合はAI生成であることを明確に表示します。H3やその生成物を、別のAIモデルの学習・改善に使用できません。必ず最新のMiniMax H3ライセンス原文を確認してください。

## 終了

- GPUを停止: GPU課金を止めます。一時ディスクは消える場合があります。
- Podを完全削除: Network Volume未使用時はモデル・履歴も消え、継続ストレージ料金を残しません。

生成物を端末へ保存してから終了し、RunPodコンソールで実際の停止状態を確認してください。
