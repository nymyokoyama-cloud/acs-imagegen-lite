# ACS Developer掲載ページ案

公開状態: 下書き。外部公開未実施。

## タイトル案

RunPodでKrea2画像＋MiniMax H3動画を始める無料UI「ACS ImageGen Lite」

## リード

ComfyUIは自由度が高い一方、初めての方にはワークフローやモデル配置が難しく感じられます。ACS ImageGen Liteは、RunPod上でKrea2画像生成とMiniMax H3の3種類の動画生成をフォーム操作で始める無料スターターパックです。

## できること

- Krea2 Turbo / Rawの画像生成
- MiniMax H3のText / Image / First-Last-Frame動画生成
- H3の音声付き3〜10秒動画
- 縦長・横長・正方形など5比率
- 自分のLoRAをアップロードして使用
- 生成待ちキューとギャラリー
- GPU停止、Pod完全削除、アイドル自動停止
- 初回パスワードによる画面保護
- スマホUIからのモデル取得、進捗、安全確認、中断・再開

## 安心のための説明

個人のLoRA、生成画像・動画、履歴、認証情報は配布データに含まれていません。Krea2・H3のモデル本体も同梱せず、初回起動時に公式配布元から取得してSHA-256を確認します。H3は独自ライセンスがあるため、公式ライセンス全文の同梱、日本リージョン固定、7項目の同意履歴、サーバー側安全フィルター、AI生成ファイル識別、通報・停止方針を実装しています。

パソコンは必須ではなく、RunPodアカウント設定後はスマホだけで操作できます。モデルの保存先はRunPod側です。Network Volumeは継続保存したい人だけの任意契約です。接続しない場合もPod稼働中の一時ディスクは従量課金ですが、Podの完全削除完了後は継続ストレージ料金が発生しません。終了ボタンの結果にかかわらず、最後にRunPodコンソールでPodが消えたことを確認します。RunPod利用料は利用者負担です。
